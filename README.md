📊 Financial Data Analysis Dashboard

 📌 Overview

 
The Financial Data Analysis Dashboard is an interactive Power BI project that provides insights into budgets, expenses, profit/loss, and transaction trends. It enables users to monitor financial performance through dynamic visualizations and KPI metrics for better decision-making.


🚀 Features


- Interactive Power BI dashboard
- Budget and Expense analysis
- Profit/Loss tracking
- KPI Cards for key financial metrics
- Dynamic slicers and filters
- Category-wise and monthly analysis
- Interactive charts and visualizations

📈 Dashboard Insights

- Total Budget
- Total Expense
- Total Profit/Loss
- Average Profit %
- Total Transactions
- Category-wise Performance
- Profit/Loss Status
- Monthly Financial Trends

💻 Technologies Used

- Power BI
- Microsoft Excel
- Power Query
- DAX
